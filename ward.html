Ward Visitor Request Collector Guide

OVERVIEW
The Ward Visitor Request Collector is a professional PowerShell native Windows Forms application designed for hospital radio stations[cite: 7]. It streamlines patient request collection, local library track availability querying, secure Base64 encrypted configuration via bin_res\db_connect.txt, dynamic station-specific UAC synchronization (_uac.txt), live network management, direct thermal printer execution, show notes coordination, and automated session exporting managed through a WVRC.ini configuration setup[cite: 7].

1. SYSTEM REQUIREMENTS & SETUP
• Environment: Windows PowerShell (compatible with Windows 10/11)[cite: 7].
• Core Dependencies: System.Windows.Forms and System.Drawing assemblies (automatically loaded by the script)[cite: 7].
• Data & Configuration Storage:
  - WVRC.ini: Stores application settings including Station ID, active username, Wi-Fi parameters, printer IP/credentials, and the administrator password[cite: 7].
  - bin_res\db_connect.txt: Base64 encrypted configuration file containing remote links for the database and UAC files[cite: 7].
  - _uac.txt (e.g., rugby_uac.txt): Local station-specific User Access Control file containing base64-encoded user permission records[cite: 7].
  - hr.txt: Local library database file stored in the bin_res directory[cite: 7].
• Subdirectories: Automatically provisions bin_res, Reports, and Show Notes folders upon startup[cite: 7].

2. CONFIGURING NETWORK, PRINTER & SECURITY SYNC (SETTINGS & IMPORT TAB)
• Admin Access & Password Security: The Settings tab is protected behind an administrative password lock to prevent unauthorized configuration changes[cite: 7]. Enter the administrator password (default is hospital or configured value) to unlock the configuration panel, with settings persisted within WVRC.ini[cite: 7].
• Station ID Configuration: Modify the station prefix (e.g., rugby) to automatically map local UAC and library database files[cite: 7].
• Encrypted Import Routine: Click "Download & Sync from db_connect.txt" to decode Base64 configurations, download the latest remote library database, and synchronize the station UAC file[cite: 7].
• User Access Control (UAC) Selection: View decrypted granted users in the list box and click "Set Active User from Granted List" to assign the active collector username[cite: 7].
• Network & Wi-Fi Management: Click "Scan Networks" to populate available wireless SSIDs[cite: 7]. Select your target network, enter enterprise credentials (Network Username and Password) or standard WPA2-PSK passwords, and click "Connect Net" to generate profile XML, apply via netsh, and connect[cite: 7]. Use "Disconnect Net" to safely terminate wireless sessions[cite: 7].
• Printer Configuration: Enter the Wi-Fi Printer IP, username, and password[cite: 7]. Click "Ping Test Printer" to verify network connectivity and save all preferences by clicking "Save to WVRC.ini"[cite: 7].

3. MANAGING PATIENT REQUESTS & FORM WORKFLOW (PATIENT FORM TAB)
• The primary operational hub is the Patient Form tab, combining request intake, database verification, and live show notes[cite: 7].
• Request Details: Date is auto-populated in dd_MM_yy format[cite: 7]. Specify the ward name and select the request source type (Patient, Staff, Visitor, Dedication, Filler), along with the source name[cite: 7]. Collector name is automatically populated from the active user configuration[cite: 7].
• Track Information: Enter Artist Name, Song Title, and an optional Alternative track suggestion[cite: 7].
• Library Availability Query: Click "Query Library" to verify track availability against the local database (hr.txt) under strict UAC validation[cite: 7].
• Printer Operations: Click "Connect Print" to verify and lock printer connectivity[cite: 7]. Click "Print" to dispatch raw text job data directly to port 9100[cite: 7]. Click "Disc. Print" to safely release the printer connection[cite: 7].
• Saving & Show Notes: Use the Show Notes / Dedication Chat text box to log on-air messaging, shoutouts, or special dedications[cite: 7]. Click "Save & Next Patient" to append the request to the active session list and clear form fields for the next entry[cite: 7].

4. STUDIO RECALL & EXPORT (STUDIO RECALL & EXPORT TAB)
• Session Recall: View all requests captured during the current session in the list box and click "Refresh Session List" to synchronize updates[cite: 7].
• Load External Files: Click "Load from Saved File..." to import previously saved report text files from the Reports directory into the studio recall view[cite: 7].
• Subfolder Export: Click "Generate Subfolder Report Files" to automatically generate and export three distinct files formatted with today's date tag[cite: 7]:
  - Central playlist file (Requests_.txt) in bin_res[cite: 7].
  - Comprehensive daily report (Reports_.txt) in Reports[cite: 7].
  - On-air show notes log (Show Notes_.txt) in Show Notes[cite: 7].
