Show Notes App - Live Production Hub Guide

OVERVIEW
The Show Notes App - Live Production Hub is a professional PowerShell native Windows Forms application designed to streamline show notes management, live request intake, priority flagging, network connectivity, printer configuration, analysis tracking, and session logging through a ShowNotes.ini configuration setup.

1. SYSTEM REQUIREMENTS & SETUP
• Environment: Windows PowerShell (compatible with Windows 10/11).
• Core Dependencies: System.Windows.Forms and System.Drawing assemblies (automatically loaded by the script).
• Data & Configuration Storage:
  - ShowNotes.ini: Stores application settings including AdminPassword, DataDirectory, printer details, and Wi-Fi parameters.
  - Cumulative ShowNotes.txt: Master history file maintaining pipe-delimited records: Timestamp | SourceChannel | SenderName | RequestDetails | Priority | AssignedSegment.
  - processed shownotes.txt: Tracks processed text files to prevent duplicate loading.

2. SHOW NOTES & LIVE REQUESTS (SHOW NOTES & REQUESTS TAB)
The primary operational hub is the Show Notes & Requests tab, combining rundown loading and live request intake.
• Show Notes Display: Click "Load Latest Show Notes" to scan the designated directory for text files and load the most recent production rundown into the read-only display view.
• Add Live Request / Note Group:
  - Source Channel: Select the intake channel from options including Email, Phone, Messaging, Website, Social Media, WhatsApp, Walk-In, or Other.
  - Sender / Caller: Input the name of the person submitting the note or request.
  - Priority Flag: Assign a priority level such as Normal, High, Urgent / Live On-Air, or Filler.
  - Request / Note Details: Enter the message, call details, or track request text.
• Save Action: Click "Add Live Note ->" to validate entries, append the record to Cumulative ShowNotes.txt, and clear input fields for the next entry.

3. CONFIGURING NETWORK, PRINTER & SECURITY (SETTINGS TAB)
The Settings tab is protected behind an administrative password lock to prevent unauthorized configuration changes.
• Admin Access & Password Security: Enter the administrator password (default is hospital) into the password field and click "Unlock Settings" to access the configuration panel.
• Unified Directory Path: Modify or browse for the custom directory path where show note text files are stored.
• Printer Configuration & Credentials:
  - Click "Scan Printers" to discover available local printers via Windows discovery.
  - Select the printer type (Hard-Wired or Wi-Fi / Network).
  - Enter printer credentials (Printer User / ID and Printer Password) and click "Test Print" to verify communication.
• Wireless Network Configuration: Click "Scan Networks" to populate available wireless SSIDs. Enter network user ID and password if required, then click "Connect Network" or "Disconnect Network".
• Diagnostics & Persistence: Click "Test Internet Connection" to verify web connectivity, and click "Save All Changes to ShowNotes.ini" to persist preferences.

4. ANALYSIS & PRINT FUNCTIONS (ANALYSIS & PRINT TAB)
• Run Analysis: Click "Run Analysis" to process the cumulative show notes history file, displaying total logged items and recent entries.
• Printer Status & Management: Monitor the real-time Active / Inactive indicator (green for active, red for inactive) and use the dedicated "Connect" and "Disconnect" buttons.
• Print Operations: Click "Print Report" to execute print jobs, protected by automated active printer checks.
